💡 O que mudou de uma para a outra?
1. No ul.horizontal tiramos o width: 200px; para que a barra ocupe a largura da tela.
2. Adicionamos float: left; no ul.horizontal li para colocar os botões lado a lado.
3. Adicionamos overflow: hidden; no ul.horizontal para a caixinha cinza abraçar os botões flutuantes.
